ВодоГрай Android V19

Ця версія вже містить Project URL і Supabase Publishable Key у config.js.
Publishable key призначений для мобільних/клієнтських застосунків; секретний ключ у застосунок не додається.

ПЕРЕД ТЕСТОМ:
1) Виконати файл supabase_setup_v19.sql у Supabase SQL Editor.
2) У Supabase Auth за потреби вимкнути Confirm email для тестування логіну без підтвердження пошти.
3) Після цього зібрати APK з цього Android Studio проєкту.

Примітка: цей пакет є Android Studio проєктом, а не готовим APK. Фінальний APK збирається після перевірки бази та доступів.

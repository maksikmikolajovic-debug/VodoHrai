# ВодоГрай V35 — Android

Проєкт для складання Android APK через GitHub Actions. Вихідний інтерфейс узято з наданого V34 `index.html`; конфігурацію — з наданого `config.js`.

## Android (із телефона)
1. Створіть **новий приватний** репозиторій GitHub (або резервну гілку).
2. Завантажте **вміст** цього ZIP, зберігаючи структуру, у корінь репозиторію.
3. Вкладка Actions → Build VodoHrai V35 APK → Run workflow.
4. Після успішної збірки завантажте artifact `VodoHrai-V35-debug-APK` і встановіть APK.

**Увага:** debug APK — тестова збірка, не Play Store release. Інтеграція з Supabase і фінансові операції потребують перевірки на реальних пристроях.

**Відоме обмеження:** Excel-експорт через `blob:` у WebView Android поки не реалізований, тому для нього використовуйте веб-версію. Не застосовуйте APK для робочого фінансового обліку, доки не буде виправлено цей пункт і проведено інтеграційні тести.

Не публікуйте конфіденційні ключі чи дані клієнтів у публічному репозиторії. `config.js` містить лише publishable ключ, не service-role.
